# Andsroid Enterprise management modes
source_url: https://developers.google.com/android/work

A work profile separates work apps and data from personal apps and data on a personally owned device. The organization manages the work profile while the personal profile remains separate.

A fully managed device is intended for company-owned devices used exclusively for work. The organization can manage the entire device and apply a broader set of policies.

Company-owned devices with work profile combine organization control over the work profile and selected device-wile policies with a spearate personal profile.
